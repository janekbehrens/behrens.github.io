Three progress bars on every issue

Three custom field types. Use one, two or all three on the same issue; each has its own red, yellow and green bar.

  • Status: follows the workflow status. A Jira admin sets what each status is worth.
  • Subtasks: the average of the subtasks' status progress. Without subtasks it uses the child issues, for example the issues of an epic.
  • Manual: a slider in 5% steps with quick buttons for 0, 10, 25, 50, 75 and 100%.

A project overview on your dashboard

The Progress Tracker Overview gadget lists the issues of a project with their progress and the average on top.

  • Pick how it calculates: from the status, from the subtasks, or the Manual field's values.
  • Narrow it down with your own JQL, for example a fix version.
  • Sort by key, summary, type, status or progress. Up to 500 issues per gadget.
More in the docs →

One bar per epic, or per person

The Epic Progress Tracker gadget rolls a project up into one bar per epic, calculated from its child issues. Switch the grouping to see progress per assignee instead.

  • Group by epic or by assignee.
  • Measure by issue count or by story points.
More in the docs →

Progress in Jira list views

All three fields work as columns in Jira's list view, each with a colored dot and the percentage. Scan a whole project without opening a single issue.

  • Manual, Status and Subtask progress side by side.
  • List columns use fixed colors: red below 34%, yellow below 67%.
More in the docs →

Your statuses, your colors

Jira admins decide what each workflow status is worth and where the bars turn from red to yellow to green. The fields and both gadgets use these settings for the whole site.

  • Add your own statuses, for example "In QA".
  • Thresholds between 1 and 99%, with a live preview.

Setup

Running in three steps

1

Install

Get the app from the Atlassian Marketplace and confirm the installation on your Jira site.

2

Add the fields

Create the progress fields in Jira settings (Work items → Fields) and add them to your project screens.

3

Done

Status and Subtask progress calculate themselves. Manual progress is one click on the field.

FAQ

Common questions

More answers in the documentation, or write to support@janekbehrens.de.

What Jira version do I need?
Visual Progress Tracker needs Jira Cloud. It is a Forge app and runs on Atlassian's infrastructure. There is no Data Center or Server version.
Is it free for small teams?
Yes. Jira sites with up to 10 users use it for free, with all three field types and both dashboard gadgets. Larger sites start with a free trial.
Can I use several field types on the same issue?
Yes. All three field types work side by side on the same issue. A common setup is a Manual field for a rough estimate and a Subtask field for the detailed view.
Do the list view colors follow my thresholds?
No. In Jira list views the columns use fixed colors: red below 34%, yellow below 67%, green from 67%. The bars on the issue and in both dashboard gadgets follow the thresholds a Jira admin sets.
Does any data leave Atlassian's infrastructure?
No. The app runs on Atlassian Forge. No external servers operated by Janek Behrens are involved. Details in the Trust Center.
