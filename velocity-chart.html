FAQ

Common questions

More answers in the documentation, or write to support@janekbehrens.de.

How is this different from Jira's built-in velocity report?
Jira's report lives on the board's Reports page and uses that board's Done column and estimation setting. Velocity Chart is a dashboard gadget: you choose which statuses count as done and how to estimate, chart up to four boards in one gadget, and get an average say/do ratio and CSV/SVG export (Pro).
Does an issue that was carried over count in both sprints?
Only as committed. Completed adds up the issues that were done when the sprint closed, as in Jira's own velocity report. An issue that was carried over unfinished counts as completed only in the sprint in which it was finished. Committed is the work that was in the sprint when it started.
Does it work with team-managed projects?
Yes. Team-managed Scrum boards appear in the board picker tagged “team-managed” and use the same calculation as company-managed boards.
Which Jira do I need?
Jira Cloud and a Scrum board with at least one closed sprint. Velocity Chart is a Forge app and runs on Atlassian's infrastructure; there is no Data Center or Server version. Classic Kanban boards have no sprints and are not listed.
Does the app change my Jira issues?
No. Velocity Chart only reads sprint data and requests no write permissions. It caches the computed numbers in Atlassian's Forge storage. No external servers operated by Janek Behrens are involved. Details in the Trust Center.
Is it free?
Jira sites with up to 10 users use it for free; larger sites start with a free trial. Without an active subscription, for example after the trial, the gadget keeps working in Free mode: one board, up to 7 sprints, the board's estimation and its Done column.
