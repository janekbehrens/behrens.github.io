Before you reach out

Most questions are answered in the documentation: it covers installation, field types, admin settings, list view columns and both dashboard gadgets. Common ones:

  • The Status bar shows 0% even though the issue has a status: the status is probably not in the status mapping. Add it with its exact name and save. Then open the issue again, or click Recalculate All Fields to update all issues.
  • Existing issues show "—" after adding the field to a project: Status and Subtask values are calculated when an issue is opened, so issues nobody has opened yet stay empty. Click Recalculate All Fields on the app's page to fill them.
  • The Recalculate button shows a date instead of running: recalculation is limited to once every 7 days, and the page shows the next available date. Single issues recalculate when opened, so you rarely need it.
  • Recalculate says "no field values were written": usually the Status and Subtask fields are not on the issue screens of those projects. Add them under Jira settings → Work items → Screens, then run Recalculate All Fields again.
  • The colors did not change after changing the thresholds: click Save Settings on the Color Settings tab and reload the issue. List view columns always use the fixed 34% and 67% limits.

What to include in a bug report

  • Your Jira site URL
  • The field type (Manual, Status or Subtask) or the dashboard gadget involved
  • What you expected vs. what you saw (a screenshot helps a lot)
