Facts from Git, always current on the page

A sync block shows a value, a table, a section or code from a file in your repository. CodeDoc updates it on every push, daily, weekly or when you click Update now.

  • Values from YAML or JSON, a README section, the latest CHANGELOG entry, a snippet between marker comments, a line range or the whole file.
  • Normal page text: Confluence search, export and page history include it.
  • A new page version only when the file changed. No AI involved.

Paste a link, pick what to show, preview

Type / on a page, choose CodeDoc Sync Block and paste the link to a file. CodeDoc fills in repository, branch and path.

  • Pick keys, headings or snippets from the file instead of typing them.
  • The preview shows the result before you save; problems come with the next step.
  • Only Job Operators and admins choose where content comes from.

The newest release next to each version

Optional for values and regular expressions: CodeDoc looks up the newest release of what the value names and shows a status such as Up to date, Update available or End of life.

  • Docker Hub images, npm and PyPI packages, GitHub releases.
  • Support dates from endoflife.date for products such as nginx, PostgreSQL or Node.js.
  • Only the public name of the image or package goes to the registry.

FAQ

Common questions

More answers in the documentation, or write to support@janekbehrens.de.

What is a sync block?
A block you add to any Confluence page with /. It shows a value, a table or a section from a file in your repository, for example the current version from a Helm chart or the Installation section of a README, and CodeDoc keeps it up to date. Sync blocks don't use AI, so they cause no token costs. Read the guide.
Do I need an AI key?
Not for sync blocks: they need only a read-only Git access token. AI pages need Atlassian AI, included in CodeDoc Advanced, or your own Anthropic, OpenAI or Google Gemini key. With your own key, your provider bills you directly and CodeDoc adds no markup.
Which Git events update a page?
With the CodeDoc webhook in the repository, blocks and AI pages set to On every push update on pushes from GitHub, GitLab, Bitbucket and Azure DevOps. GitLab merge request events and merged pull requests on Bitbucket and Azure DevOps count too; on GitHub a merge arrives as a push. Without a webhook, choose a daily or weekly update. Details: Webhook setup.
Which Confluence version do I need?
CodeDoc needs Confluence Cloud. It is a Forge app and runs on Atlassian's infrastructure; there is no Data Center or Server version. It can read your own GitHub Enterprise or GitLab server if that server is reachable from Atlassian's cloud.
How long does setup take?
Most teams are connected in about 5 minutes. You need a read-only Git access token. AI pages also need Atlassian AI (Advanced edition) or your own AI provider key. The Quick start walks you through every step.
Does my code leave Atlassian's infrastructure?
Sync blocks send nothing to an AI provider. For AI pages, the Forge runtime fetches the selected files and sends them either to Atlassian AI (Advanced edition; the code stays on Atlassian's platform) or directly to your own AI provider. No servers operated by Janek Behrens are involved at any point. Details in the Trust Center.
