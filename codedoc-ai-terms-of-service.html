2. Description of the App

CodeDoc is a Confluence Cloud app that keeps Confluence pages in sync with files in source code repositories and, optionally, generates documentation pages with AI. The App provides:

  • Integration with Git hosting providers (GitHub, GitLab, Bitbucket Cloud, Azure DevOps, and your own GitHub Enterprise or GitLab servers) to read source code.
  • Sync blocks that show and update parts of repository files on Confluence pages, optionally with the newest release from public registries.
  • Integration with AI providers (Anthropic, OpenAI, Google AI) with your own keys, and in the Advanced edition with Atlassian-hosted AI, to generate documentation.
  • Automated publishing of generated documentation as Confluence pages.
  • Manual, webhook-based, and scheduled trigger mechanisms for documentation generation.
