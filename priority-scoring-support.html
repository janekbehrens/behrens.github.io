Before you reach out

Most questions are answered in the documentation (FAQ & troubleshooting). Common ones:

  • The score sliders don't appear on my issues: the field is almost always missing from the project's screen. Add it under Jira Settings → Work items → Screens; in a team-managed project under Project settings → Issue types (details).
  • Rovo applied scores but Board Health still shows the issues as "Unscored": the Priority Scoring field is probably not on the project's screen. Fix the screen setup, then click Refresh on the app page.
  • Rovo says a score could not be applied: name one of RICE, WSJF or ICE and give every dimension of that framework. Until the values are complete, nothing is written and the existing score stays as it is.
  • A gadget says "Priority Scoring cannot show" a project: you don't have permission to browse that project in Jira, or the project no longer exists. Ask a Jira administrator for the Browse Projects permission, or edit the gadget and choose a project you can open.
  • I can't change the settings: only Jira administrators can change Priority Scoring settings, because they apply to everyone on the site. The Health Criteria of a project can also be changed by that project's administrators.
  • The Rovo portfolio comparison leaves out a project: it summarises up to 5 projects from their Board Health of the last hour. Other projects need a Check in the Portfolio tab first (details).

What to include in a bug report

  • Your Jira site URL, and whether it relates to the RICE, WSJF or ICE fields, the dashboard or the Rovo AI agent
  • Custom fields: which framework (RICE / WSJF / ICE) is affected, and whether the field is missing from the issue view or shows incorrect values
  • Rovo AI agent: which action was triggered (suggest / apply / bulk), the configured apply mode, and the exact response or error message shown in Rovo chat
  • Dashboard / gadget: the project key, the selected framework, and the exact message or number you see. For the Rovo portfolio comparison: whether the project's Board Health was calculated in the last hour (for example with Check in the Portfolio tab)
